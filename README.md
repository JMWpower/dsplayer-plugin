# dsplayer-plugin

DsPlayer 插件市场仓库：`market.json` 为市场索引（在线安装入口），`packages/` 存放插件包，`icons/` 存放条目图标，`check_market.py` 为发版前对账闸门（在仓库根目录执行）。

市场地址（DsPlayer 内添加）：

```
https://raw.githubusercontent.com/JMWpower/dsplayer-plugin/main/market.json
```
